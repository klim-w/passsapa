# PassSapa - Solo Creator Payment Setup (ไม่ต้องใช้ Statement / ไม่ต้องมีนิติบุคคล)

**เวอร์ชัน**: 1.1.0  
**เหมาะสำหรับ**: Solo Creator / บุคคลธรรมดา (ไม่มี Statement, ไม่มีจดทะเบียนบริษัท)

---

## 🏆 วิธีการตั้งค่าที่สมัครง่ายที่สุด 100% (No Statement Required)

สำหรับผู้ที่ไม่มี Bank Statement หรือไม่ได้จดทะเบียนบริษัท **ไม่ต้องกังวลเลยครับ!** เราใช้ **บัญชีออมทรัพย์ธนาคารบุคคลธรรมดาที่คุณมีอยู่แล้ว** ในการรับเงินได้ทันที โดยแบ่งออกเป็น 2 ทางเลือกง่ายๆ:

---

### 📍 ทางเลือกที่ 1: ระบบแจ้งเตือนโอนเงิน + แอดมินกดยืนยัน 1-Click (งบ 0 บาท & สมัครง่ายที่สุด!)

* **เอกสารที่ต้องใช้**: **ไม่มีเลย!** (ใช้เลข PromptPay / บัญชีออมทรัพย์เดิมของคุณได้ทันที)
* **การทำงาน**:
  1. ผู้เรียนโอนเงินเข้า PromptPay บัญชีบุคคลธรรมดาของคุณ แล้วแนบรูปสลิป
  2. รูปสลิปและข้อมูลจะถูกส่งเข้า **LINE Notify บนมือถือของคุณ** ทันที
  3. คุณเปิดดูบนโทรศัพท์มือถือ แล้วกดปุ่ม **`[ ✅ อนุมัติสิทธิ์ VIP ]`** เพียง 1 วินาที
  4. สิทธิ์ในระบบของผู้เรียนจะถูกเปิดใช้งาน VIP ทันที 24 ชม.

---

### 📍 ทางเลือกที่ 2: ใช้ SlipOK API อนุมัติอัตโนมัติ 24 ชม. (สมัครง่ายใน 2 นาที)

* **เอกสารที่ต้องใช้**: **อีเมลอย่างเดียว!** (สมัครบนเว็บ SlipOK.com)
* **การสมัคร**:
  1. เข้าเว็บ `SlipOK.com` กรอกอีเมลและตั้งรหัสผ่าน (สมัครเสร็จใน 2 นาที)
  2. เติมเครดิตเริ่มต้น 50 - 100 บาท (จ่ายตามจริง สลิปละ 50 สตางค์)
  3. **ไม่ต้องส่ง Bank Statement หรือเอกสารการเงินใดๆ ทั้งสิ้น**
* **การทำงาน**: ระบบของ PassSapa จะยิง API ไปเช็กภาพสลิปที่ SlipOK เพื่อตรวจสอบชื่อผู้รับและยอดเงิน และอนุมัติสิทธิ์ให้อัตโนมัติใน 2 วินาทีโดยที่คุณไม่ต้องเฝ้าน่าจอเลยครับ!

## ⛔ ทำไมไม่แนะนำระบบตัดบัตร (Opn / Stripe / GB Prime Pay) ในช่วงแรก?

| ระบบชำระเงิน | เอกสารที่ยุ่งยาก | ต้องใช้ Statement ไหม? |
| :--- | :--- | :---: |
| **Opn / GB Prime Pay** | ต้องใช้ทะเบียนพาณิชย์, บัญชีนิติบุคคล, Statement ย้อนหลัง 6 เดือน | ❌ **ต้องใช้ ยุ่งยากมาก** |
| **Stripe Thailand** | ต้องส่งเอกสารยืนยันตัวตนหลายขั้นตอนสำหรับบุคคลธรรมดา | ❌ **มีโอกาสอนุมัติยาก** |
| **PromptPay + SlipOK** | **ใช้อีเมลอย่างเดียว + บัญชีธนาคารเดิมของคุณ** | ✅ **ไม่ต้องใช้ Statement 100%** |
