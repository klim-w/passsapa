# PassSapa - UX/UI Design System & Formal Typography

**เวอร์ชัน**: 1.1.0  
**แนวคิดหลัก**: สุภาพ ทางการ เป็นทางการเหมือนตำราสภาการแพทย์แผนไทย (Formal Academic Identity)

---

## ✒️ 1. ระบบแบบอักษรทางการ (Formal Typography System)

เพื่อให้เนื้อหาบนเว็บมีความเป็นทางการ อ่านง่าย ถนอมสายตา และมีสไตล์เหมือนตำราเรียนวิชาการแพทย์แผนไทยและเว็บ `saatthai.com`:

* **ฟอนต์เนื้อหาข้อสอบ & คัมภีร์หลัก (Body Text & Scriptures)**: **`Sarabun` (TH Sarabun New)**
  * *จุดเด่น*: ฟอนต์ทางการของสภาการแพทย์แผนไทยและราชการไทย ตัวอักษรมีหัว อ่านโจทย์ยาวๆ ข้อสอบ กฎหมาย และคัมภีร์ได้อย่างสบายตา ไม่ล้าสายตา
* **ฟอนต์หัวข้อและปุ่มกด (Headings & UI Buttons)**: **`Prompt` / `Kanit`**
  * *จุดเด่น*: ทันสมัย หนักแน่น สุภาพ ชัดเจน

---

## 🎨 2. อัตลักษณ์สี (Color Palette Tokens)

### ☀️ Light Mode Theme (โหมดสว่างแนวสุภาพ)
* **Background**: `#F8FAF9` (ขาวอุ่นมรกตอ่อน สบายตา)
* **Card Surface**: `#FFFFFF` (ขาวบริสุทธิ์ ขอบเงาละมุน)
* **Primary Accent**: `#0D9488` (เขียวมรกตสุภาพ Teal-Emerald)
* **Secondary Accent**: `#D97706` (ทองสมุนไพร/ตำราอ้างอิง)
* **Text**: `#111827` (ดำเทา อ่านง่าย คอนทราสต์สูง)

### 🌙 Night Mode Theme (โหมดมืดถนอมสายตายามค่ำคืน)
* **Background**: `#070D0C` (ดำหยกเข้ม สบายสายตา)
* **Card Surface**: `#0F1917` (ดำมรกตซ้อนมิติ)
* **Primary Accent**: `#10B981` (เขียวมรกตเรืองแสงนวล)
* **Secondary Accent**: `#F59E0B` (ทองเปล่งประกายสำหรับคัมภีร์/VIP)
* **Text**: `#F3F4F6` (ขาวนวล อ่านสบาย)
