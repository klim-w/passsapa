# Excel Template & Validation Skill

Skill นี้ใช้เป็นข้อกำหนดแม่แบบไฟล์ Excel (`.xlsx` / `.csv`) และสคริปต์สำหรับการสกัด ตรวจเช็ก และนำเข้าข้อสอบเข้าสู่ฐานข้อมูลคลังข้อสอบ PassSapa

---

## 📊 1. โครงสร้างคอลัมน์มาตรฐานในไฟล์ Excel (Excel Column Spec)

| ชื่อคอลัมน์ (Column Header) | คำอธิบาย | ตัวอย่างข้อมูล | บังคับไหม? |
| :--- | :--- | :--- | :---: |
| `category` | สาขาการสอบ (เวชกรรมไทย, เภสัชกรรมไทย, ผดุงครรภ์ไทย, นวดไทย, กฎหมาย) | เวชกรรมไทย | ✅ บังคับ |
| `scripture_ref` | ชื่อคัมภีร์หรือหัวข้ออ้างอิง | คัมภีร์ตักกศิลา | ✅ บังคับ |
| `question_text` | โจทย์คำถาม | ไข้ปะตังมีลักษณะอาการตามข้อใด? | ✅ บังคับ |
| `option_a` | ตัวเลือก A | ผื่นแดงขึ้นทั่วตัว ปวดศีรษะ | ✅ บังคับ |
| `option_b` | ตัวเลือก B | เม็ดกระจุกคล้ายข้าวสาร | ✅ บังคับ |
| `option_c` | ตัวเลือก C | ตุ่มดำ ปวดกระดูก | ✅ บังคับ |
| `option_d` | ตัวเลือก D | คอแข็ง เอี้ยวคอไม่ได้ | ✅ บังคับ |
| `correct_option` | คำตอบที่ถูกต้อง (`a`, `b`, `c`, `d`) | a | ✅ บังคับ |
| `explanation` | คำอธิบายเฉลยและหน้าอ้างอิงตำรา | อ้างอิงคัมภีร์ตักกศิลา ไข้ปะตังมีผื่นแดงขึ้นทั่วตัว... | ✅ บังคับ |
| `image_url` | ลิงก์รูปภาพประกอบข้อสอบ (ถ้ามี) | https://passsapa.com/images/herb1.jpg | ⚪ ไม่บังคับ |

## 🔍 2. กฎการตรวจเช็กความถูกต้องก่อนบันทึก (Validation Rules)

1. **Duplicate Question Check**: ระบบจะเปรียบเทียบข้อความโจทย์ หากพบว่าโจทย์ซ้ำกับที่มีใน DB จะทำการแจ้งเตือนแอดมินล่วงหน้า
2. **Correct Option Match**: ค่าในคอลัมน์ `correct_option` ต้องเป็น `a`, `b`, `c`, หรือ `d` เท่านั้น
3. **No Empty Fields**: ต้องไม่มีช่องโจทย์หรือตัวเลือกว่าง
